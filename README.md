# 🐾 PetCam — 寵物監視器

免費、免安裝、長輩友善的寵物即時監控 Web App。  
用一支舊 Android 手機當攝影機，透過 WebRTC 點對點加密串流，隨時觀看家中毛孩。

## 功能

- 📱 **PWA 支援** — 加到主畫面即可像 App 一樣啟動
- 🎥 **即時影像** — WebRTC P2P 加密串流，免費無需伺服器
- 🎤 **雙向對話** — 按住說話，跟貓咪互動
- 👴 **長輩友善** — 無障礙字體、高對比配色、超大按鈕
- 🔒 **隱私保護** — 被觀看時發出提示音、螢幕自動變黑
- ⚡ **防休眠** — Wake Lock API 保持攝影機持續運作

## 使用方式

1. **舊手機**打開 `camera.html` → 點擊「啟動攝影機」
2. **觀看端**打開 `viewer.html` → 輸入攝影機 ID → 開始觀看

- **前端**: 純 HTML/CSS/JS（無框架）
- **通訊**: WebRTC + PeerJS（免費信令伺服器）
- **部署**: GitHub Pages（免費 HTTPS）
